# SONORA — Your Music Universe

A responsive, neon-galaxy music dashboard built as a static HTML/CSS/JavaScript app.

## Features
- Dark purple visual identity and responsive desktop/mobile layouts
- Mood filters, search, liked songs, and track cards
- Interactive demo player with play/pause, next/previous, progress and volume controls
- Animated sound visualizer and album art
- Keyboard shortcuts: Ctrl/Cmd + K to search, Space to play/pause

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy
This is a static website; GitHub Pages or Vercel can host it directly.

## Important
The current player is a UI prototype. It does not stream the sample tracks or authenticate with Spotify. Real Spotify playlists and playback require Spotify OAuth, app configuration, and playback integration. Do not expose a Spotify client secret in browser code.
